\section{Worked Example: Comparing Candidate Models}
\label{app:model-comparison-tutorial}

\subsection{Purpose of the example}

This worked example illustrates how fitted curves, performance metrics, cross-validation, residual plots, Q--Q plots, and parameter uncertainty results can be considered together when comparing candidate models. It provides practical examples of residual patterns that can help readers interpret their own results; further illustrated examples are available in \cite{motulsky1987, kutner2005, nistResidualAnalysis, psuResidualExamples, originlabResidualPlotAnalysis}. The dataset is simulated so the underlying relationship is known, but the comparison is presented in the same way as an analysis of an unknown experimental relationship. The example is intended as a practical demonstration, not as an acceptance procedure or a set of model-selection criteria.

An accompanying Python script generates a noisy single-exponential decay dataset and fits four candidate models. The four candidate models fitted to the primary dataset are:

\begin{itemize}
    \item a linear model, included as a form that does not match the data-generating process and is expected to demonstrate clear lack of fit;
    \item an exponential model, which matches the form used to generate the data;
    \item a stretched-exponential model, which can reduce error slightly by adding a shape parameter; and
    \item a double-exponential model, which can reduce error further while adding parameters that may be weakly estimated and strongly coupled.
\end{itemize}

This example uses the same fitting functions, performance metrics, shuffle-split cross-validation constructor, and relative evidence calculations used by the app. The figures use a simplified layout rather than reproducing the interactive app displays exactly.

\subsection{Start with the fitted curves}

Figure~\ref{fig:tutorial-fitted-curves} shows the simulated observations with all four fitted curves. The fitted curve display is the first opportunity to identify clearly implausible behavior, but models that differ meaningfully can appear similar when the response scale is large relative to the residual differences. For this example, the linear model visibly misses the decay shape. The three exponential-family models can appear similar at the scale of the response plot, even though the stretched and double-exponential forms use additional parameters.

\subsection{Compare fit metrics, model complexity, and cross-validation}

Table~\ref{tab:tutorial-model-summary} reports goodness-of-fit metrics, AIC\textsubscript{c} comparisons, cross-validation error, and a compact parameter-correlation summary. These quantities answer different questions. \(R^2\) and RMSE describe agreement with the fitted observations. AIC\textsubscript{c} compares relative empirical support while penalizing additional fitted parameters. Cross-validation RMSE describes prediction error for omitted observations. The ratio of cross-validation RMSE to full-fit RMSE provides a simple indication of how much prediction error increases when part of the dataset is excluded from fitting.

In addition to its visible lack of fit, the linear model has substantially poorer fit metrics. Its \(R^2\) remains moderately high because it captures part of the large overall change in response, even though it does not describe the curved decay pattern well. The exponential model provides the strongest overall balance: it represents the generating relationship with only two parameters and has the lowest AIC\textsubscript{c}. The stretched and double-exponential models reduce RMSE slightly, but their higher AIC\textsubscript{c} values indicate that these small improvements do not offset the added complexity. Cross-validation provides a separate check on how prediction error changes when observations are omitted from fitting. The cross-validation results are similar to the full-fit results for the linear, exponential, and stretched-exponential models. In contrast, the double-exponential model gives much poorer cross-validation performance, indicating greater sensitivity to the observations used for fitting.

\subsection{Use residuals versus time to look for missed structure}

Residuals are calculated as observed minus predicted response (i.e., the prediction errors). A suitable fitted form generally leaves residuals distributed around zero without sustained curvature or adjacent groups that remain mainly above or below zero. Figure~\ref{fig:tutorial-residuals} uses the same y-axis range for all four models so the sizes and patterns can be compared directly.

\begin{figure}[h!]
    \centering
    \includegraphics[width=0.6\textwidth]{tutorial/generated/residuals_vs_time.pdf}
    \caption{Residuals versus time for the four fitted models.}
    \label{fig:tutorial-residuals}
\end{figure}

The linear residuals show a pronounced systematic pattern, indicating that the model does not represent the curved decay well. The exponential residuals fluctuate around zero without any sustained structure. The stretched and double-exponential models produce similarly centered residuals that are slightly smaller at some observations, but this modest improvement should be considered alongside their added complexity, AIC\textsubscript{c}, cross-validation behavior, and parameter uncertainty.

\subsection{Use Q--Q plots to review residual distribution shape}

A normal Q--Q plot compares ordered standardized residuals with the quantiles expected from a normal distribution. Points close to the reference line are broadly consistent with the assumed residual distribution. Curvature, separation at the ends, or an isolated point can draw attention to skewness, heavy tails, or an unusual residual. With a small dataset, the plot has limited resolution and is interpreted together with the residual-versus-time plot rather than as a formal confirmation of normality.

\begin{figure}[h!]
    \centering
    \includegraphics[width=0.6\textwidth]{tutorial/generated/qq_plots.pdf}
    \caption{Normal Q--Q plots of standardized residuals.}
    \label{fig:tutorial-qq}
\end{figure}

These Q--Q plots do not distinguish the candidate models as clearly as the residual-versus-time plots, largely due to the small number of observations. A Q--Q plot describes the residual distribution, whereas a residual-versus-time plot is more directly informative about systematic lack of fit across the observed profile. For this dataset, the app would not display Q--Q plots for the exponential-family models because the residual variation is too small relative to the overall response range. Instead, it would report that the Q--Q diagnostic is not informative rather than magnifying very small numerical differences.

\subsection{Effect of the number of observations}
\label{sec:tutorial-number-of-points}

Figures~\ref{fig:tutorial-fitted-curves}--\ref{fig:tutorial-qq} use the primary dataset with 9 observations. To illustrate the effect of denser sampling, a second independent dataset was generated from the same single-exponential relationship and noise distribution at 61 evenly spaced times from 0 to 60. Figure~\ref{fig:tutorial-dense-diagnostics} shows the fitted curves and residual diagnostics for the linear and exponential models. This section provides a qualitative example of how the number of observations can affect the ability to distinguish a suitable model from one with systematic lack of fit.

\begin{figure}[h!]
    \centering
    \includegraphics[width=\textwidth]{tutorial/generated/dense_sample_diagnostics.pdf}
    \caption{Graphical diagnostics for linear and exponential fits to a simulated dataset with 61 evenly spaced observations: fitted curves, residuals versus time, and normal Q--Q plots.}
    \label{fig:tutorial-dense-diagnostics}
\end{figure}

The smaller dataset already suggests that the linear model does not capture the decay relationship, but the denser dataset makes the lack of fit easier to diagnose. With more observations, the linear residuals form a clearer systematic pattern over time rather than fluctuating randomly around zero, and departures from the Q--Q reference line are easier to assess. In contrast, the exponential-model residuals remain comparatively patternless around zero and follow the Q--Q reference line more closely. Additional observations do not guarantee selection of a suitable model, but they provide more information for distinguishing systematic lack of fit from random variation. With sparse data, the same patterns may be less apparent or more easily mistaken for noise.

The exponential parameters are expected to be estimated comparatively precisely because the fitted model matches the generating relationship, and indeed their relative standard errors are only a few percent. For the stretched exponential, the estimated shape parameter remains close to the single-exponential value of 1, so the added parameter changes the fitted curve only slightly and does not improve AIC\textsubscript{c}. In the double-exponential fit, both components retain nonzero amplitudes (\textit{a} and \textit{c}), but the amplitudes and rate parameters (\textit{b} and \textit{d}) have very large uncertainty and are almost perfectly coupled. The fitting procedure can trade one component against the other while producing nearly the same overall curve. In the app, this combination of high parameter correlation and elevated relative standard errors would receive an \emph{identifiability caution} badge. This illustrates why a slightly closer fitted curve does not necessarily support the added model structure or interpretation of the individual component parameters.

\subsection{Integrated interpretation}

No single output determines the preferred candidate. In this example, the linear model is readily set aside because the fitted curve and residual pattern show clear lack of fit. The exponential model provides the strongest overall balance: it captures the curve shape without obvious residual structure and does so with the fewest parameters among the plausible candidates. The stretched and double-exponential models can achieve slightly lower error, but their higher AIC\textsubscript{c} values indicate that the improvement does not justify the added complexity for this dataset. The double-exponential parameter results provide an additional caution because both fitted components remain active while their amplitudes and rates are extremely uncertain and strongly coupled.

For an experimental analysis, the same workflow can be applied without knowing the generating model: inspect the fitted curves, compare complementary metrics, review cross-validation as a sensitivity diagnostic, examine residual-versus-time and Q--Q plots, and consider parameter uncertainty and scientific plausibility before documenting the user-selected model.
