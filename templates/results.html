Approach 1: Direct Correlation Results

This tab shows each fitted direct-correlation model separately. It includes:

  • Plot: matched in vitro and in vivo time points with the fitted model overlay.
  • Function: mathematical equation of the fitted model.
  • Model parameters: coefficients reported as estimate ± 95% confidence interval.
  • Fitted parameter diagnostics: brief badges that flag parameter uncertainty, coupling, or identifiability cautions.
  • Goodness of fit: selected fitted-data metrics, eligible cross-validation metrics, fit/CV ratios, and CV comparison badges.
  • Residual diagnostics: residual-vs-x plots with common residual-scale reference bands to help visually identify possible bias or residual patterns, plus normal Q-Q plots for a qualitative residual-normality check.

This tab shows each model family fitted independently to the in vitro and in vivo datasets. It includes:

  • Plot: both datasets with separate fitted model curves.
  • Function: mathematical equation of the fitted model family.
  • Model parameters: in vitro and in vivo coefficients reported as estimate ± 95% confidence interval.
  • Fitted parameter diagnostics: brief badges shown separately for the in vitro and in vivo fits.
  • Time constant: fitted characteristic time scale where available.
  • Goodness of fit: selected fitted-data metrics, eligible cross-validation metrics, fit/CV ratios, and CV comparison badges for each dataset.

Model Selection & Summary

This tab lets you choose the fitted approach/model after reviewing model fits and comparison metrics. Prediction-specific methods are only shown when a prediction dataset was supplied and successfully processed.

  • User selection: the app does not rank or recommend a model in this tab. The first option is only the initial UI default.
  • Fit-only reports: if no prediction dataset was supplied, the selector lists only approach/model combinations and omits prediction-method choices.
  • Prediction reports: if prediction data were supplied, the selector also lists available prediction methods such as response-value ratio or time-constant-ratio rescaling.
  • Report summary: includes preprocessing choices, analysis settings, method description, relevant plots, parameter estimates, goodness-of-fit statistics, and uncertainty/error-bar assumptions.
  • Word export: creates an editable .docx from the selected report content. Plotly figures are exported as static images and embedded in the Word file.
  • Manual review: confirm that plots, residuals, parameter uncertainty, cross-validation behavior, and scientific expectations support the chosen model.
