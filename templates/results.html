Model Comparison

This section provides statistical comparisons between different models:

  • Performance Metrics: Quantitative measures of how well each model fits the data
  • Kolmogorov-Smirnov Test: Statistical test comparing model predictions (p-values shown)

For Model Selection:

  • Look for models with lower error metrics (e.g., RMSE)
  • Prefer models with higher R² values (closer to 1.0)
  • Use K-S test p-values to identify significantly different models. A p-value of 1.0 indicates identical models, so the diagonal values are all 1.0. A p-value < 0.05 implies a significant difference between models.
  • Consider the Information Criteria (AIC/BIC) - lower values indicate better model fit with appropriate complexity
    • AIC (Akaike Information Criterion): Balances model fit with complexity. Lower values are better.
    • BIC (Bayesian Information Criterion): More conservative than AIC, penalizes complexity more heavily. Lower values are better.
    • Interpretation: Differences < 2 indicate equivalent models; differences > 6 show strong evidence for the lower-value model.
    • When they disagree: AIC favors prediction accuracy; BIC favors simpler, more interpretable models.

Approach 1: Direct Correlation Results

Shows results from direct correlation between in vitro and in vivo data:

  • Plot: Scatter plot with fitted model overlay
  • Function: Mathematical equation of the fitted model
  • Parameters: Coefficients with uncertainty estimates (± std. err.)
  • Goodness of Fit: Statistical measures and cross-validation results

For Model Selection:

  • Look for high R² values and lower error metrics (e.g., RMSE)
  • Use Information Criteria (AIC/BIC) to balance model fit with complexity - lower values indicate better models that avoid overfitting
  • Consider parameter uncertainty - smaller ± values indicate more reliable estimates
  • Compare cross-validation results to final model performance - similar values of correlation coefficients and error metrics indicate good generalization

Approach 2: Independent Model Fitting Results

Shows results from independent fitting to each dataset:

  • Plot: Both datasets with separate fitted models
  • Function: Mathematical equation of the fitted model
  • Parameters: Coefficients with uncertainty estimates (± std. err.)
  • Time Constant (Tau): Characteristic time scale of the process
  • Separate Statistics: Goodness of fit for each dataset

For Model Selection:

  • Look for high R² values and lower error metrics (e.g., RMSE) for both datasets
  • Use Information Criteria (AIC/BIC) to balance model fit with complexity - lower values indicate better models that avoid overfitting
  • Consider parameter uncertainty - smaller ± values indicate more reliable estimates
  • Compare time constants between datasets for consistency with your expectations
  • Compare cross-validation results to final model performance - similar values of correlation coefficients and error metrics indicate good generalization

Approach 3: Direct Mapping Results

Shows direct comparison between interpolated datasets:

  • Value vs. Time Plot: Difference between dataset values over time
  • Time vs. Value Plot: Ratio of dataset times across value ranges

For Model Selection:

  • Identify trends or patterns that could inform model-based correlation strategies
  • Consider this approach when model-based methods fail or show poor fits

  • Predicted Data: Corresponding in vivo time points calculated using fitted correlation between in vitro and in vivo time

Approach 2: Prediction Results

Shows predictions using independent model ratios:

  • Input Data: Your in vitro prediction dataset
  • Predicted Data: In vivo predictions where the in vitro time in the prediction dataset has been scaled using either:
    • the ratio of the in vivo/in vitro times from the fitted models that correspond to the in vitro prediction values; or
    • the ratio of the time constants, if available.
  • Fitted Models: Both in vitro and in vivo model curves

Approach 3: Prediction Results

Shows direct mapping predictions:

  • Input Data: Your in vitro prediction dataset
  • Predicted Data: In vivo predictions where the in vitro time in the prediction dataset has been directly scaled by the ratio of in vivo/in vitro times in the fitting datasets
  • Connection Lines: Show the time scaling transformation

    • Points in the in vitro prediction dataset that are outside the range of the fitting datasets (time range when scaling by value, or value range when scaling by time) are excluded.
