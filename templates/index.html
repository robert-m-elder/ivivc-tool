Data Upload

This section allows you to upload datasets for IVIVC analysis:

  • Fitting Dataset: Required dataset containing in vitro and in vivo data for model fitting
  • Prediction Dataset: Optional dataset for making predictions using fitted models

Supported formats: CSV, Excel (.xlsx, .xls)

Dataset for Fitting

Upload a file containing your in vitro and in vivo data for model fitting.

Required format:

  • 4 columns: Time1, Value1, Time2, Value2
  • Time1/Value1: In vitro data
  • Time2/Value2: In vivo data

This data will be used to establish the correlation between in vitro and in vivo measurements.

If your file for model fitting contains multiple sheets, select the sheet you want to use.

Dataset for Prediction

Optional: Upload a file containing new in vitro data for prediction.

Format:

  • 2 columns: Time, Value
  • Contains in vitro data for which you want to predict in vivo outcomes

The fitted models will be applied to this data to generate in vivo predictions.

If your file for prediction contains multiple sheets, select the sheet you want to use.

Analysis Approaches

Choose the overall way the app should relate the in vitro and in vivo datasets:

  • Approach 1: directly relate matched in vitro and in vivo time points.
  • Approach 2: fit the same type of curve separately to each dataset.
  • Approach 3: create a direct data-based mapping without fitting a parametric model.

Approach 1: Direct Correlation

Directly relates matched in vitro and in vivo time points, then uses the fitted relationship to map in vitro time to predicted in vivo time.

Method:

  • Fits a model to paired in vitro and in vivo time points.
  • Requires matched time points or interpolation to create matched pairs.
  • Uses the fitted relationship as a time-scaling function.

Useful when: the two datasets have matching time points, or interpolation can create matched pairs, and the main question is how in vitro time corresponds to in vivo time.

Approach 2: Independent Model Fitting

Fits the same model family separately to the in vitro and in vivo datasets, then compares the two fitted curves for prediction.

Method:

  • Fits the selected model form independently to each dataset.
  • Can calculate predictions using fitted response ratios or fitted time constants, when available.
  • Does not require the original time points to match exactly.

Useful when: datasets have different time scales or sampling schedules, or when a specific degradation-curve shape is scientifically meaningful for both datasets.

Approach 3: Direct Mapping

Creates direct mappings between the datasets without fitting a parametric model.

Method:

  • Uses interpolation-based ratios or mappings calculated from the supplied data.
  • Provides two scaling options for predictions.
  • Does not assume a specific equation for the degradation pattern.
  • Requires matched values or interpolation to create comparable points.

Useful when: the analysis is exploratory, a simple equation does not describe the observed pattern well, or a direct data-based mapping is preferred.
