Data Upload

This section allows you to upload datasets for IVIVC analysis:

  • Fitting Dataset: Required dataset containing in vitro and in vivo data for model fitting
  • Prediction Dataset: Optional dataset for making predictions using fitted models

Supported formats: CSV, Excel (.xlsx, .xls)

Dataset for Fitting

Upload a file containing your in vitro and in vivo data for model fitting.

Required format:

  • 4 columns: Time1, Value1, Time2, Value2
  • Time1/Value1: In vitro data
  • Time2/Value2: In vivo data

This data will be used to establish the correlation between in vitro and in vivo measurements.

If your file for model fitting contains multiple sheets, select the sheet you want to use.

Dataset for Prediction

Optional: Upload a file containing new in vitro data for prediction.

Format:

  • 2 columns: Time, Value
  • Contains in vitro data for which you want to predict in vivo outcomes

The fitted models will be applied to this data to generate in vivo predictions.

If your file for prediction contains multiple sheets, select the sheet you want to use.

Analysis Approaches

Choose from different mathematical approaches for establishing IVIVC:

  • Approach 1: Direct time correlation between datasets
  • Approach 2: Independent rate equation-like model fitting
  • Approach 3: Direct mapping analysis

Each approach uses different mathematical methods and assumptions. Approaches 1 and 2 use cross-validation to validate the models.

Approach 1: Direct Correlation

Establishes a direct mathematical relationship between in vitro and in vivo data points.

Method:

  • Fits models directly in vitro vs. in vivo time
  • Predicts in vivo time as a function of in vitro time
  • Requires matched time points or the use of interpolation

Best for: When you have well-matched time points between datasets or use interpolation.

Approach 2: Independent Model Fitting

Fits separate models to in vitro and in vivo data, then uses their ratio for predictions.

Method:

  • Fits rate equation-like (e.g., exponential decay) models independently to each dataset
  • Calculates predictions using model ratios
  • Provides effective time constants for in vitro and in vivo

Best for: When datasets have different time scales or sampling patterns, or when you want to fit a particular rate equation to the datasets.

Approach 3: Direct Mapping

Creates direct mappings between interpolated datasets without model fitting.

Method:

  • Uses interpolated data for direct comparison
  • Provides two scaling options for predictions
  • No parametric model assumptions
  • Requires matched time points or the use of interpolation

Best for: Exploratory analysis or when model assumptions may not hold.

Advanced Analysis Parameters

These options control model validation and the initial parameter search used before nonlinear curve fitting.

  • Cross-validation scheme: validation splitter used for Approaches 1 and 2.
  • CV splits/folds: number of repeated splits for ShuffleSplit or folds for K-fold.
  • ShuffleSplit test size: fraction of observations held out in each ShuffleSplit repeat.
  • CV random seed: seed used for reproducible randomized validation splits.
  • Grid-search random starts: number of starting points sampled before final curve fitting. Higher values are more robust but slower.
  • Grid-search parameter min/max: lower and upper bounds for the initial parameter-value search. These bounds affect the starting values passed to nonlinear fitting.
